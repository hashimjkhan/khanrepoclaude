# Wonky Links

Mini golf on courses that are generated fresh every game. Open `index.html` in any browser.

- **Solo** or **Pass & play** (2–4 players on one device) work offline.
- **Play with friends online**: one person creates a game and shares the code. Everyone opens the same page on their own phone. No accounts needed. Connections go peer-to-peer through the free PeerJS service, with its relay servers as a fallback.

To host it on GitHub Pages: repo **Settings → Pages → Deploy from a branch**, pick the branch and `/ (root)`. The game will be at `https://<user>.github.io/<repo>/wonky-links/`.
